## How to use these blueprints

- The actual catalog path is `courses[].official.exam.sections` in `src/lib/catalog/data/courses.json`. The issue's `exam.sections` is shorthand. Each course is identified below by its catalog ID.
- Counts are published exam item counts, not a guarantee of scored-item counts. Use these for assembly; do not silently subtract assumed pretest questions. FRQ question count is not the number of response parts or rubric rows.
- Minutes refer to standard timed work. Breaks, administrative instructions, accommodations, and through-course projects are separate. Reading time explicitly included in a section is not extra time.
- Weights refer to the total AP score unless a note explicitly says “of the section.” Parent and child weights overlap; never add both. Published rounded weights are retained. Composite scoring policy belongs to DEV-198.
- “Current page” means the live official exam page consulted on this date. A 2027 date on that page is weaker evidence of a revision than an explicit effective-year notice. Dated revisions take priority over superseded content, and disagreements are identified rather than silently reconciled.
- Official requirements and repository observations are stated separately. App readiness is an engineering inference, not a claim made by College Board.

## DEV-194 implementation handoff (engineering recommendations)

1. Load the existing per-course official data rather than duplicating it in hardcoded course switches. Return a clear unsupported result when necessary counts, timing, or required capabilities are missing. Preserve the source and effective-year context of each blueprint.

3. Preserve course order and task quotas. Task-controlled courses must select the required task types, not randomly sample all FRQ formats. ### App compatibility and open questions

All 13 courses have MCQ practice enabled in `courses[].app.practice`; only Biology and Chemistry have FRQ practice enabled. These switches do not establish that full-length exams or exact task distributions exist. `courses[].official.exam.sections` stores section counts and time, and Calculus/Precalculus have part information; it does not itself drive proof of delivery.

Implementation inference: `src/lib/exams/session.ts` permits only `mcq` and `frq` section kinds, each with a single nullable time limit and items; the strict schema has no nested parts, calculator policies, weights, task dependencies, separate Create portfolio artifacts, or dedicated reading/planning time. It can represent separately timed subparts as independent sections, but that alone does not prove official navigation, scoring, calculator enforcement, mixed question interaction, or CSP project workflow. The saved response contract is a string per item. Verify the actual session UI and persistence before claiming any stronger capability.

Open: for these specific courses the pages consulted do not identify a separate reading/planning period; this is not proof no instructions or planning time exist within the published durations. The official pages publish 42-question counts for Physics, Calculus, Precalculus, Statistics and Computer Science A; how many are scored, including whether any are pretest questions, is unresolved here. Calculus subpart percentages of total score are not explicitly supplied on current pages; do not derive them from counts without an authoritative scoring source. The precise split of CSP's 30% between code/video and written responses is not asserted here. Current official course pages and calculator policy should be rechecked closer to 2027 administration for changes.

### Catalog comparison and design implications

- Catalog indices are based on the order in `courses.json`; course units are stored in `courses[].units` (not `app.units`). All 13 exam formats are present under `courses[].official.exam.sections`.
- Most counts and total section durations agree with current official exam pages. English and social-science courses fit the app's MCQ + FRQ practice core structurally, although realistic practice needs stimulus passages/data/images and course-specific rubrics.
- History needs more than generic MCQs and open-response prompts: SAQs, document-based synthesis, and LEQs have distinct source/prompt requirements. For May 2027 onward, don't teach the old elective history SAQ format; all three source-based SAQs are required. In the current CED, the obsolete optional SAQ choice remains visible in places, notably European History, so use the 2027 exam update and Fall 2026 CED correction as controlling.
- Economics is hybrid and requires graph drawing plus numerical analysis. A text-only FRQ core cannot fully reproduce the booklet or graph construction. Only a four-function calculator is allowed in both sections (including built-in Desmos); handheld scientific and graphing calculators are prohibited ([College Board calculator policy](https://apcentral.collegeboard.org/exam-administration-ordering-scores/administering-exams/exam-policies/calculator-policy)). Catalog values of 66% + 33% sum to 99% because College Board publishes rounded percentages. How DEV-198 should represent the composite score without implying precision is deferred to that task.
- Spanish is a major departure from generic MCQ/FRQ practice: 2027 asks students to prepare and present project-based spoken Spanish, answer recorded questions, and write an evidence-based essay using print and audio. A generic written FRQ cannot cover its speaking/audio behavior. The current official exam page sets the essay at 55 minutes including two audio listening opportunities, and specifies 25 listening MCQs in 40 minutes and 30 reading MCQs in 40 minutes. The revised CED describes an initial six-minute source-reading/listening protocol; the current exam page's 55-minute essay timing subsumes that protocol, so it should not be added as a separate block. The schema's Q&A duration stores a rounded three-minute value, whereas the official task instruction specifies four responses of 40 seconds each.
- Art History is structurally six essay FRQs, requiring image-aware comparison, visual and contextual evidence, and attribution. Text-only question generation would omit central exam evidence.
- For 2027, AP world-language format details are officially published, while some test previews and operational instructions remain scheduled for January 2027. This report uses the 2026–27 CED and current exam pages for blueprint claims, and treats the released Psychology task pacing as optional within a shared section clock.
